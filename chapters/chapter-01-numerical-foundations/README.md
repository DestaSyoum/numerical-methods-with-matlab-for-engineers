# Chapter 1: Numerical Foundations

## Chapter overview

Numerical methods are used when an engineering model cannot be solved conveniently by exact analytical methods, or when the required information is available as measured or simulated data. This chapter establishes the workflow for numerical problem solving, introduces the MATLAB practices used throughout the course, and explains the main sources of numerical error.

## Learning outcomes

After completing this chapter, students should be able to:

1. translate an engineering question into a computational model;
2. distinguish variables, parameters, assumptions, and constraints;
3. use MATLAB arrays, operators, scripts, and functions appropriately;
4. distinguish roundoff error from truncation error; and
5. use a convergence or error study to assess a numerical result.

## 1.1 Mathematical modelling and numerical problem solving

Numerical work starts with a model, not a MATLAB command. A sound workflow is:

1. define the engineering question and required outputs;
2. identify variables, parameters, units, and assumptions;
3. formulate governing equations or data relationships;
4. choose an appropriate numerical method;
5. verify the calculation using a residual, limiting case, exact solution, or refinement study; and
6. communicate the result with its assumptions and limitations.

Every numerical answer should be interpreted in its engineering context. A result may be mathematically correct but physically unsuitable when the model assumptions are not valid.

## 1.2 MATLAB foundations for numerical work

MATLAB represents most numerical data as arrays. Use vector operations whenever the same calculation is applied to each element:

```matlab
x = 0:0.1:2*pi;
y = sin(x).^2;
```

The dot in `.^`, `.*`, and `./` requests elementwise operations. Without it, MATLAB performs matrix operations. Preallocate arrays in loops, use meaningful variable names, and label all figures with variables and units.

## 1.3 Scripts, functions, and reproducibility

Use a **script** to demonstrate a worked problem and a **function** to implement a reusable algorithm. A well-designed numerical function should state its inputs, outputs, tolerance, iteration limit, and conditions under which it can fail.

The course examples follow this convention:

- `src/` contains reusable algorithm functions;
- `examples/` contains worked demonstrations; and
- `figures/` contains plots generated by the examples.

## 1.4 Roundoff and truncation errors

### Roundoff error

Computers represent real numbers with finite precision. Roundoff error arises when a number cannot be represented exactly or when subtraction removes significant digits.

### Truncation error

Truncation error arises when an infinite mathematical process is replaced by a finite approximation. A finite-difference derivative, for example, omits higher-order terms from a Taylor expansion.

### Balancing errors

Reducing a step size often reduces truncation error at first. However, an extremely small step can increase roundoff error. The useful step-size range is the region where total error is minimized.
