# Applied Numerical Methods with MATLAB

An original, code-first study companion for **Applied Numerical Methods with MATLAB for Engineers and Scientists** by Steven C. Chapra. It is organised around the book's 24-chapter outline, but all explanations, examples, code, and figures in this repository are independently written.

## Why this repository exists

The goal is to turn numerical-methods coursework into a small, reproducible engineering portfolio. Each completed topic contains:

- a short concept note;
- readable MATLAB implementations of the algorithm (rather than only calling a built-in function);
- an example script with a practical engineering-style problem; and
- a generated figure when visual comparison is useful.

## Run it

Open MATLAB in the repository root and run the current chapter:

```matlab
addpath('src'); addpath('examples');
root_finding_demo
optimization_demo
```

All figures are written to `figures/` by the scripts, so they are reproducible rather than copied from a textbook.

## Academic and copyright note

This is not a replacement for the textbook. It deliberately does not reproduce the book's prose, end-of-chapter questions, solutions, or artwork. The chapter titles are used only as a study roadmap; all repository content is original.

## Skills highlighted

MATLAB programming, numerical stability awareness, signal analysis, linear algebra, regression, interpolation, numerical integration, and differential-equation modelling.
